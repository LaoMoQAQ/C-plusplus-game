# v0.5.0

从 v0.4.0 以来的一次集中更新：修掉了长期存在的退出崩溃、存档不可用、闪屏等问题，界面向常规 galgame 靠拢。

## 重点修复

**退出时崩溃（0xC0000005）**

原本在 `Game::Quit()` 里先调 `TTF_Quit()` / `SDL_Quit()`，再让成员对象析构。`FontManager` 析构时要释放 `TTF_Font*`，此时 FreeType 已经关闭，于是访问非法内存。

改为 `Shutdown()` 按依赖顺序先释放资源、后关子系统。

**存档不可用**

原来只有单一存档文件，覆盖式保存。改为固定 10 格槽位 + 缩略图，读档页能看到每一格的时间与进度。

**新游戏残留好感度 / 剧情结束卡死**

开始新游戏时没有清空好感度记录，导致继承上一局数据。剧情走到末尾没有正确处理，返回标题失效。两者都已修正。

## 画质与界面

**多级降采样模糊**

原来只做一次 1/4 缩放，边缘有明显的方块感。改为连续多级、每级减半，等价于多次盒式滤波，结果接近高斯模糊。

级数最终定为 **3 级**（1600×900 → 800 → 400 → 200）。4 级会降到 100×56，糊成一片色块，只剩「糊」没有「玻璃」；3 级保留形状轮廓，能看出「后面有东西」。

**暂停菜单毛玻璃**

暂停时的背景不再是剧本背景图，而是**玩家按下 ESC 那一刻实际看到的画面**。整屏模糊后叠一层半透明白（强度 28），做出磨砂玻璃质感。

强度调过几轮：40 会让浅色背景整片发白、白字看不清；18 只有模糊感没有玻璃颗粒感；28 兼顾两者。

**对话框**

改为圆角（半径 24），框内能看到背景的模糊虚影，不再是纯色块。底色不透明度 150，兼顾可读性与透光感。

**移除全屏黑幕过渡**

原本每次切换界面都做 `alpha 1 → 0 → 1` 的全屏压黑，中间必然出现一帧纯黑，观感上就是闪屏，也不符合 galgame 惯例。

改为状态即时切换，切换的观感交给菜单内部动画（高亮块滑动、对话框高度缓动）。

## 闪屏的根因与修复

这是本轮最难定位的问题，表现为**背景只画了顶部一条、下方全黑**，反复出现。

根因有两层：

1. `DrawFrostedRegionRound` 把 `roundA`/`roundB` 轮流重建为降采样后的尺寸（1520×220 → 760×110 → 380×55），下一轮再重建回原尺寸。
2. `SDL_SetRenderTarget(renderer, nullptr)` **不会恢复 viewport**，它会停留在上一个渲染目标的尺寸上。

于是切回主目标后，背景和立绘全被裁到左上角 380×55 的范围内。

修复：两张缓冲改为**固定 w×h**，降采样结果只画到左上角；新增 `RestoreMainTarget()`，切回主目标时显式重设 viewport。

同时修正降采样时 `src` 传 `nullptr` 的问题——那会把整张纹理（大部分是黑的）都缩进去，越缩越黑，最终对话框背景一片纯黑。

## 其他

- BGM 支持淡入淡出
- 动画与打字速度改为帧率无关
- 好感度历史写入存档，存档格式扩展为 7 行
- Makefile 支持头文件依赖追踪（`-MMD -MP`），新增 `make release`
- 清理死代码，移除未引用的 `number.ttf`
