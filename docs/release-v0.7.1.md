# v0.7.1

修掉 v0.7.0 遗留的几个章节相关 bug。**建议所有 v0.7.0 用户更新。**

## 修复

**章节解锁永远只开第 1 章**

`StoryGraph` 的解锁逻辑本身是对的（看过第 N 章 → 解锁到 N+1），但 `visited` 集合从来没被写入过——`MarkVisited` 和 `SaveProgress` 在整个项目里一次都没调用。

结果 `FurthestVisitedOrder()` 恒为 -1、`UnlockedUpTo()` 恒为 0，只有第 1 章能选，玩多久都一样。

补上三处调用：

- `ApplyCurrentEvent()` 开头标记当前章节（新游戏、读档、章节跳转、`[下一章]` 都会经过它）
- 换章时立即 `SaveProgress("save/progress.dat")`
- `Shutdown()` 再存一次，正常退出也保住进度

> ⚠️ 旧存档没有 `progress.dat`，更新后需要重新玩一遍才能积累解锁进度。

**正常开始游戏没有章节标题卡**

只有「章节选择」和 `[下一章]` 会播。从主菜单「开始游戏」进来是直接进第一句。

在 `case 0` 里补上 `Show()`，并同时设置 `currentScript`，保证后续换章判断基准正确。

**章节选择的字号不统一**

未解锁分支走的是两参数 `DrawText` 重载，用的是默认字体 32 号；已解锁分支和副标题是 22 号。所以未选中的章节反而更大。

统一成 22 号，只靠颜色区分状态（已解锁纯白 / 未解锁灰色）。

**章节选择高亮块没有过渡动画**

`Update()` 里算好的平滑值 `displayHighlightY` 没被使用，`Render()` 用的是即时算出来的位置。鼠标移动或键盘选择时高亮块是瞬移的。

**已访问标记显示成空方框**

用的是 `✓`（U+2713），`simhei.ttf` 没有这个字形。换成 `·`（U+00B7）。

## 验证

模拟把第 1 章一路推到 ending：

```
furthest=104  unlocked=105  nodes=14
```

`progress.dat` 正确写入 11 个章节路径。章节选择页确认第 2-10 章全部可选。

SDL2 及全部依赖 DLL 已打包在内。
