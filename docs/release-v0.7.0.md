# v0.7.0

渲染后端整体换成 **OpenGL 3.3 Core**，界面统一到液体玻璃（Liquid Glass）材质，新增章节选择与章节标题卡。

## 亮点

**渲染层重写**

从 SDL2 Renderer（D3D 后端）迁移到 OpenGL 3.3 Core。纹理、绘制、模糊全部走 GLSL 着色器：

| 着色器 | 作用 |
|---|---|
| `SPRITE` | 纹理批量绘制，顶点合批 |
| `BLUR` | 标准高斯，12 对采样按 `exp(-i²/2σ²)` 加权 |
| `GLASS` | SDF 圆角 + 解析位移场 + RGB 色散 |

GL 入口点自己加载（`SDL_GL_GetProcAddress`），**不需要 GLEW / GLAD**，编译依赖和以前一样。

**液体玻璃**

四个二级菜单、对话框、章节标题卡全部改用玻璃面板：

- 用圆角矩形的 SDF 当位移场，解析算出折射方向，省掉贴图
- 外法线在 45° 分界处平滑混合，避免出现硬边斜线
- 位移量沿边界法线走，RGB 通道各差 6% 产生色散
- 折射采样的是**已模糊**的场景图，不是清晰图

面板通透度 0.52、投影 24；对话框 0.42 / 18（面积大，太实会压住立绘）。

**章节选择菜单**

玻璃面板列出全部章节：

- 已走过的打 ✓，未解锁的显示成灰色
- 上下选择自动滚动（可视 10 行）
- 右侧显示副标题（九月 · 初见 / 十月 · 靠近 / …）
- 选中后跳到该章开头

**章节标题卡**

换章时播放「第 N 章 + 副标题」：淡入 0.45s → 停留 1.25s → 淡出 0.55s。播放期间按键可跳过。

## 修复

- **对话框背景上下颠倒** — GL 的 FBO 纹理原点在左下，屏幕坐标在左上，采样时 V 没翻
- **暂停菜单背景全黑** — 暂停背景指向了场景纹理自己，清屏就黑
- **启动崩溃** — 假纹理句柄传给了 `SDL_SetTextureBlendMode`
- **退出崩溃（0xC0000005）** — 三处 `SDL_DestroyTexture(假句柄)`；同时补上 `Renderer::Destroy` 里整个纹理表的释放（之前全泄漏）
- **章节标题卡正常推进时不播** — `[下一章]` 是 `Story::Next()` 内部消化的，不走 Game 的换章分支
- **章节选择键盘无效** — 参数约定不一致，传的是 `1/2` 却比较 `SDLK_UP`
- **存档缩略图** — 接上 `glReadPixels` 回读，之前 GL 移植时被置空

## 保留的既有改进

上一版的 UI 修缮全部保留：

- 按键提示键帽样式（圆角键帽 + 说明文字 + 暗色背衬）
- 菜单标题真正居中（按实测文字宽度算）
- 存档格 2×5 布局，`CELL_H=104` 不再压住提示条
- 变化历史卡片列表（时间线圆点 + 配色变化值）
- 固定 10 格存档位，7 行存档格式
- 全屏黑幕过渡移除，状态即时切换

## 已知限制

- **立绘仍是占位素材**。AI 生成尝试过，DirectML 不支持 LoRA，无法约束「白底全身 + 指定服装」，详见 README
- **需要支持 OpenGL 3.3 的显卡**。非常老的集成显卡可能跑不起来
- 章节选择每次启动重新扫描 `script/` 目录，剧本很多时首次打开略有延迟

## 下载

`FourYears-v0.7.0.zip`（约 76 MB），Windows x64。

解压后从 `FourYears/` 目录运行 `game.exe`（**必须在这个目录下运行**，资源路径都是相对路径）。

SDL2 及全部依赖 DLL 已打包在内，无需另外安装。
