# v0.6.0

修复 v0.5.0 遗留的暂停菜单闪屏问题，其余内容与 v0.5.0 一致。

## 本次修复

**暂停菜单毛玻璃闪屏**

v0.5.0 修掉了对话框一侧的闪屏，但暂停菜单用的是另一个函数 `BlurRegionTo`，它存在**完全相同**的缺陷：

```cpp
// 旧实现：两张缓冲轮流重建为降采样后的尺寸
EnsureTarget(next, nW, nH, nw, nh);   // 1600×900 → 800×450 → 400×225 → 200×112
```

每次渲染目标尺寸变化，SDL 的 viewport 就跟着缩小且不会自动恢复。切回主目标后，背景被裁到左上角，于是出现「只画了顶部一条」的闪屏。

修复方式与 v0.5.0 一致：

- `blurPing` / `blurPong` 改为**固定 `s.w × s.h`**，降采样结果只画到左上角，渲染目标尺寸全程不变
- 降采样时 `src` 限定为上一级的有效区域，避免把黑边一起缩进去
- 使用 `RestoreMainTarget()` 恢复 viewport

**验证数据**：暂停菜单连续采样 20 帧，平均亮度稳定在 116.3，暗帧 0 个（修复前会在 26 与 95 之间反复跳变）。

## v0.5.0 完整内容

v0.6.0 包含 v0.5.0 的全部功能，未做其他改动：

### 修复

- 退出时崩溃（`0xC0000005`，`TTF_Quit` 与 `FontManager` 析构顺序错误）
- 存档不可用（改为固定 10 格槽位 + 缩略图）
- 新游戏残留上一局的好感度
- 剧情结束时无法返回标题
- 对话框圆角处露出方形模糊块
- 暂停背景不是玩家当前所见画面

### 界面

- 多级降采样模糊（3 级，每级减半，接近高斯效果）
- 暂停菜单毛玻璃（模糊 + 半透明白，强度 28）
- 对话框圆角 + 内部背景模糊虚影
- 移除全屏黑幕过渡，改为状态即时切换

### 其他

- BGM 淡入淡出
- 动画与打字速度帧率无关
- 好感度历史写入存档，格式扩展为 7 行
- Makefile 支持头文件依赖追踪，新增 `make release`
- 清理死代码，移除未引用的 `number.ttf`

## 已知限制

- 立绘资源仍为占位素材，AI 生成流程见 README「用 AI 生成立绘」
- 目前仅提供 Windows x64 构建

SDL2 相关 DLL 已包含在包内，无需另外安装。
